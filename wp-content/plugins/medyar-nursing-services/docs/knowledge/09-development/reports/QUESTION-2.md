# QUESTION-2 — چک‌لیست زندهٔ پرستار: فقط نمایش گروه یا فرم تعاملی کامل؟

## سؤال
در مسیر زندهٔ `page-checklist.php` الان گروه‌های `checklist_groups` (عنوان زیرخدمت + بندها) از `order_items` نمایش داده می‌شود. فرم تعاملی کامل (ذخیره زیر `steps.checklist.by_service`) هنوز روی مسیر fixture/پیش‌نمایش است. آیا باید همان UI تعاملی fixture برای پنل واقعی هم بازسازی شود، یا نمایش گروه‌بندی‌شده + ذخیره از API مسیر خدمت کافی است؟

## پیش‌فرض پیشنهادی
همین اتصال گروه‌ها در مسیر زنده کافی است تا مالک چک‌لیست‌های پیش‌نویس را تأیید کند؛ فرم تعاملی کامل چندخدمتی در کارت جدا بعد از تأیید متن بندها.

## وضعیت
باز — ناظر/مالک تصمیم بگیرد.
