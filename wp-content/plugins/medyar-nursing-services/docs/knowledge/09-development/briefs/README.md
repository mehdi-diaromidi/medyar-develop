# briefs — فایل‌های تحویل به Cursor (هر مرحله یک فایل)

**روش کار:** برای هر کارت یک فایل `T-m.n.md` اینجا ساخته می‌شود که **به‌تنهایی** کامل است (چه بخواند، چه بسازد، چه نسازد، چه تحویل بدهد). تو فقط همان یک فایل را به Cursor می‌دهی.

1. چت **Agent** جدید در Cursor؛ فایل `briefs/T-m.n.md` را به چت اضافه کن (`@`) و بنویس: «این فایل را دقیق اجرا کن».
2. خروجی و `git diff` را برای ناظر (Claude) بیاور؛ بازبینی می‌شود.
3. بعد از تأیید ناظر: آپلود به develop (توسط تو یا ناظر، نه Cursor) و بررسی سایت.
4. ناظر فایل کارت بعدی را می‌سازد (چون به خروجی کارت قبل وابسته است، کارت‌ها یک‌جا از قبل ساخته نمی‌شوند).
